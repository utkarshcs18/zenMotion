# ZenMotion

A collection of creative visual experiments, motion graphics, and algorithmic designs. This repository explores different mediums for generating visual art, ranging from raw WebGL shaders to procedural Python scripts.

## 📁 Contents

### 1. [background/](./background/) - Crimson Flow

A cinematic procedural WebGL background inspired by the fluid abstract visuals of Vanta.js. Crimson Flow generates immersive animated red-and-black motion entirely on the GPU using raw WebGL and GLSL shaders — lightweight, responsive, and dependency-free.

### 2. [pyDesign/](./pyDesign/) - Python Turtle Graphics

Procedural geometric pattern generators using Python's built-in `turtle` module.

- `circle_pattern.py`: Generates a swirling, spiral pattern using alternating colored circles.
- `square_circle_pattern.py`: Draws complex intersecting shapes combining squares and circles.

## 🚀 How to Run

### Crimson Flow (WebGL)

Simply open `background/background.html` in any modern web browser to view the shader animation.

### Python Designs

Ensure you have Python installed, then run the scripts from the terminal:

```bash
cd pyDesign
python circle_pattern.py
python square_circle_pattern.py
```
